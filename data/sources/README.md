このフォルダには、ネタ帳ページ[ソース]タブの[鉄板に追加]／[外す]で送信されたデータ(JSON)が溜まります。
毎日便・土曜便が回収して state.sources.manual(鉄板リスト)に反映したあと、処理済みとして整理します。

形式: {"added_at":"ISO日時", "add":[{"domain":"response.jp","note":"メモ"}], "remove":["example.com"]}
※ add / remove は片方だけのこともあります。

remove は「鉄板リストから外す」であって「今後このサイトを見に行かない」ではありません。
除外リスト(巡回対象から外す仕組み)は、2026-08-29 の決定により作りません。
判定済みの母数が溜まるまで、採用率が低いサイトも巡回対象に残します。
