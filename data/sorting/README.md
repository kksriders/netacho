このフォルダには、ネタ帳ページの[反映する]で送信された仕分けデータ(JSON)が溜まります。
毎日便・土曜便が回収してネタ帳に反映したあと、処理済みとして整理します。

## JSONのキー（便が処理するもの）
- `star` / `keep` / `thru` / `drop` … 仕分けタブの判断。番号(num)の配列
- `revive` … ゴミ箱からの復活。`[{num, to:"star"|"keep"}]`
- `pickup` … 見送りタブの[これは拾ってほしかった]。mid の配列 → 次の便で仕分け(pending)に上げる
- `miokuri_done` … 見送りタブの[確認済み]。mid の配列
  → **その mid を `netacho.miokuri` から削除する**（見終わったネタを二度と表示しないため）。
  30日の自動削除を待たずに消す。`pickup` と同じ mid が来た場合は pickup を優先し、削除しない。
